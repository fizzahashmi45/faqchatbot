# FAQ Chatbot

A simple, lightweight, and interactive web-based FAQ Chatbot designed to answer frequently asked questions instantly.

🌐 **Live Demo:** [https://fizzahashmi45.github.io/faqchatbot/](https://fizzahashmi45.github.io/faqchatbot/)

---

## 🚀 Features

- **Instant Responses:** Automatically answers common user queries.
- **Clean UI:** Simple, responsive, and user-friendly interface built with modern web technologies.
- **Lightweight:** Fast loading time with no heavy dependencies.
- **Hosted on GitHub Pages:** Accessible online directly from any browser.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
